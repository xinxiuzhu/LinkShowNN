# LinkShowNN

[Nuono](https://github.com/xinxiuzhu/Nuono) 的多平台链接解析插件，发送链接即可查看图文卡片，并可下载音视频。

## 功能

- **多平台解析**：支持 B 站、抖音、快手、小红书、Twitter/X、网易云音乐、QQ 音乐、库街区和腾讯频道。
- **图文卡片**：视频和歌曲使用统一封面海报风格，展示文案、作者信息和可获取的统计数据，附原链接二维码。
- **图集发送**：文案用纯文字，最多 3 张原图同消息发送；超过 3 张在 OneBot 群聊或私聊合并转发，最多展示 8 张。
- **热门评论**：可开关评论展示；有公开评论时取点赞最高的最多 3 条，支持头像、表情包和配图。
- **音视频下载**：支持抖音、小红书的无平台水印视频源，以及 B 站、网易云音乐、QQ 音乐播放源；先发卡片或图集，再发音视频。
- **直播订阅**：支持 B 站直播订阅与开播通知。
- **扫码登录**：B 站、网易云音乐和 QQ 音乐支持超管私聊扫码，凭据保存在 Nuono 数据库，重启自动读取。

## 使用

在 Nuono 根目录执行：

```bash
git clone https://github.com/xinxiuzhu/LinkShowNN.git plugins/LinkShowNN
cargo run --release
```

在管理界面的插件配置中调整解析、卡片和下载选项，部分平台需额外配置。解析使用 HTTP/API 与静态分享页，卡片由 Rust 原生绘制，无需安装浏览器；实际可获取的内容以平台公开数据为准。

抖音视频和图集通过公开接口匿名获取媒体、作者和统计，无需登录或外部浏览器；部分作品及评论仍受平台限制。

扫码指令：`urlB站登录`、`url网易云登录`、`urlQQ音乐登录`，仅限超管私聊；各平台还有“登录状态”“取消登录”“清除登录”指令。

网易云音乐、QQ 音乐默认直连平台，无需自部署 API；免费歌曲可匿名获取音源，会员歌曲按登录账号权益获取，试听会明确标注。
